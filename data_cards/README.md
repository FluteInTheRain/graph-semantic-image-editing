# data_cards/ — thẻ mô tả dữ liệu

**Data card là gì?** Một trang mô tả ngắn cho mỗi bộ dữ liệu: nguồn, phiên bản, giấy phép, thống kê, cách chia, hạn chế. Giúp người khác tái lập và giúp nhóm trả lời vấn đáp.

| File (sẽ tạo) | Bộ dữ liệu |
|---|---|
| `data_cards/visual_genome.md` | Visual Genome |
| `data_cards/fb15k237_img.md` | FB15k-237-IMG |
| `data_cards/mkg_wy.md` | MKG-W / MKG-Y |
| `data_cards/mmkg_vi.md` | MMKG tiếng Việt tự xây (bắt buộc ở cấp độ 3) |

Mục tối thiểu mỗi card: Nguồn & phiên bản · Giấy phép · Thống kê (đỉnh, cạnh, ảnh) · File split dùng · Cách liên kết ảnh - thực thể · Hạn chế & rủi ro · Ngày tải.
