# reports/ — báo cáo, slide, phân tích

| Đường dẫn | Nội dung |
|---|---|
| `reports/report/` | Báo cáo kỹ thuật 12–18 trang (nguồn LaTeX/Markdown + PDF bản nộp) |
| `reports/slides/` | Slide trình bày (≤ 20 phút) |
| `reports/case_studies/` | Phân tích ≥5 truy vấn thành công + ≥5 truy vấn thất bại |

Bảng phân công đóng góp từng thành viên nằm trong báo cáo, khớp với lịch sử commit (xem `CONTRIBUTING.md`).
